# Mezdoc

Insurance document automation for US managing general agents (MGAs), wholesale brokers and
program administrators. Build each document once, fill it from a link, an embed or the REST API,
and Mezdoc assembles the packet by the rules your team sets.

- Product: https://mezdoc.com
- API docs and samples: https://mezdoc.com/developers
- Postman collection: https://mezdoc.com/postman/mezdoc.postman_collection.json
- Contact: hello@mezdoc.com
